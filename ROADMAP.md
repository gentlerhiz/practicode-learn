# Roadmap

This roadmap shows what we plan, in order. It is not a promise of dates. We will update it as we learn from learners.

## Phase 0: Design (now)

- [x] Positioning, personas, business model
- [x] Competitive and UI research
- [x] Standards framework, teaching model, lesson format
- [x] Four track syllabi
- [x] Design system and core UI designs (landing, dashboard), shortlisted to three visual directions
- [x] Choose the final visual direction (Prism) and design the remaining v1 screens: sign-up, checkout, project workspace, module check, settings, AI tutor and site assistant
- [ ] v1 spec approved
- [ ] Implementation plan approved
- [ ] Willingness-to-pay survey with 100+ prospective learners (validates regional pricing)
- [ ] Usability test of the lesson player prototype with 5 learners, on low-end Android phones

## Phase 1: Foundation (MVP)

Goal: a learner can sign up, finish Module 1 of any track for free, start a Pro trial and continue.

- Landing page, regional pricing, sign-up and onboarding (goal and experience level)
- Lesson player with the PRIMM step types, in-browser HTML, CSS and JS runner, and reduced-motion support
- Learner dashboard: resume, daily review, weekly goal, skill map
- AI tutor in the lesson player (hints first, daily caps) and the site assistant on marketing pages
- Daily review queue (FSRS)
- Front-End Web Development: Module 1 free, Modules 2–4 Pro
- Module 1 for Data Analysis, UI/UX Product Design, and AI & ML
- Subscriptions with local payment methods
- Accessibility audit (WCAG 2.2 AA) and performance budget in CI

## Phase 2: Depth

- Remaining modules on a published release schedule, one track at a time
- Projects with automated test feedback
- Offline module packs (PWA)
- Python in the browser (Pyodide) for AI & ML
- Verified certificates as Open Badges 3.0
- Mentor plan integration with PractiCode Academy cohorts
- Scholarship applications and sponsor-a-learner

## Phase 3: Scale

- Interface translations (French, Kiswahili, Arabic, Hausa, Yoruba, Igbo, prioritised by demand)
- Exam-prep pathways (for example, PL-300)
- Schools and teams plan (universities, SIWES programmes)
- Public impact dashboard
- Cybersecurity track, aligned to the NICE Framework (needs sandboxed lab infrastructure)
- 1EdTech certification for Open Badges issuing

## How we decide priorities

1. Does it help a learner reach mastery faster?
2. Does it work on a low-end phone over a weak connection?
3. Can we measure its impact?
