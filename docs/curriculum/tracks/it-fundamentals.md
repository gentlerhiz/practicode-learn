# IT Fundamentals: Computers and Digital Skills

*Syllabus v0.1 (draft for practitioner review) · Licensed under CC BY-SA 4.0*

> **Understand the technology you use every day, use it with confidence, and know where you could go next.**

| | |
|---|---|
| **For** | Complete beginners with no tech knowledge, and anyone who wants solid foundations before a technical course |
| **Prerequisites** | None. Being able to tap and type on a phone is enough to start. |
| **Estimated effort** | ~45 hours across 13 modules (about 85 lessons) plus a capstone (≈ 3 months at 4 hours a week) |
| **Tools** | Our own practice labs in the browser: a desktop, a file manager, a command line (Windows and Mac/Linux), a network and a spreadsheet. Nothing to install. |
| **Primary alignment** | [CompTIA Tech+ (FC0-U71)](https://www.comptia.org/certifications/tech) objectives: IT concepts and terminology, infrastructure, applications and software, software development concepts, data and database fundamentals, and security |
| **Also aligned to** | [DigComp 2.2](https://publications.jrc.ec.europa.eu/repository/handle/JRC128415), the EU's digital competence framework (all five areas) · SFIA 9 level 1 (Follow): USUP, ITOP |
| **Credential** | PractiCode Learn Certificate: IT Fundamentals (Open Badges 3.0), plus an optional Tech+ exam-prep pathway |

## By the end, you can

1. Explain how a computer turns input into output, and describe the main kinds of computer and what each is for.
2. Read a device's specifications and choose a device that fits a need and a budget.
3. Install, update and remove software safely, and explain the difference between open-source, free and paid software.
4. Organise files and folders, and move around and manage files from the command line on Windows and on Mac or Linux.
5. Explain how a home network and the internet carry data, and fix common connection problems.
6. Decide what belongs on your device and what belongs in the cloud, and keep a working backup.
7. Use documents, spreadsheets, email and video calls well, and share files with the right permissions.
8. Explain what data, databases, programming and AI are, and use AI assistants critically.
9. Troubleshoot a problem methodically and ask for help in a way that gets it solved.
10. Describe what the main roles in tech involve day to day.

## Lessons

Each lesson takes 8–12 minutes and follows the [lesson format](../lesson-format.md).

1. **How computers work** (6): What is a computer? · Input, processing, output and storage · Kinds of computer · A short history of computing · Binary: how computers count · Bits, bytes and data sizes
2. **Inside the machine** (7): The processor · Memory and storage are not the same · Hard drives and SSDs · Graphics and screens · Ports, cables and wireless · Reading a spec sheet · Choosing a device
3. **Operating systems and software** (7): What an operating system does · Windows, macOS and Linux · Android and iOS · Installing and removing apps safely · Updates, and why they matter · File types and default apps · Licences: open source, free and paid
4. **Files, folders and the command line** (9): Files and folders · The folder tree and paths · Using a file manager · Meet the command line · Where am I, and what's here? · Moving around: cd · Making and copying files and folders · Moving, renaming and deleting · No undo: working safely
5. **Networks and the internet** (7): What a network is · Routers, modems and Wi-Fi · IP addresses · DNS, the internet's contacts list · How a web page reaches you · Bandwidth, speed and mobile data · When the internet is "down"
6. **Local and the cloud** (6): Local and cloud storage · Sync is not backup · Software, platforms and infrastructure as a service · Data centres: where the cloud lives · Cost, privacy and working offline · The 3-2-1 backup rule
7. **Everyday productivity** (7): Writing and formatting documents · Spreadsheets: cells, rows and formulas · Presentations that people follow · Email that gets answered · Calendars and video calls · Sharing and permissions · Keyboard shortcuts that save hours
8. **Data and databases, the basics** (5): Data and information · Structured and unstructured data · Tables, records and fields · What a database does · Asking a table a question
9. **How software gets made** (6): What programmers actually do · Algorithms: steps in order · Flowcharts and pseudocode · Programming languages · Your first tiny program · Version control, in a sentence
10. **AI and new technology** (6): What AI is, and isn't · Machine learning in plain words · Using an AI assistant well · Checking what AI tells you · Smart devices and the Internet of Things · AR, VR and what's next
11. **Staying safe and well** (6): Passwords and two-factor sign-in · Spotting phishing · Updates and antivirus · Your digital footprint · Screen time, posture and eyes · Accessibility features everyone can use
12. **Troubleshooting** (6): A method for any problem · Restart, and why it works · Common problems and fixes · Searching for answers well · Asking for help: a good support request · Writing it down
13. **Roles in tech** (7): The map of tech roles · Support and networking · Cloud and infrastructure · Software development · Data and AI · Security · Design and product

## Labs

The practice runs in labs built into the lesson player, so a phone is enough for every module:

- **Computer parts** (Module 1): input, processing, output and storage, one step at a time.
- **Binary switches** (Module 1): flip bits and watch the number change.
- **Data sizes** (Module 1): a text, a photo, a song and a film, set against the space on a phone.
- **Practice desktop and file manager** (Modules 3–4): a simulated computer to install, organise and tidy.
- **Command line** (Module 4): Windows (`cd`, `dir`, `copy`, `move`, `del`) and Mac/Linux (`cd`, `ls`, `cp`, `mv`, `rm`) side by side, on a practice file system that can be reset.
- **Network** (Module 5): a home network to break and fix.
- **Spreadsheet** (Modules 7–8): cells, formulas and a small table to query.

## Assessment

In-lesson tasks with instant checks, module mastery checks (80% pass mark), rubric-marked projects, and a capstone. The exam-prep pathway adds timed practice tests that mirror the Tech+ domains.

## Device notes

Every module works on a phone. A computer helps in Modules 4 and 7, where trying the same commands and apps on a real computer makes the lessons stick, but the labs cover everything the lessons ask.
