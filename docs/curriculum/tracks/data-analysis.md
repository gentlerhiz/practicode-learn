# Data Analysis

*Syllabus v0.1 (draft for practitioner review) · Licensed under CC BY-SA 4.0*

> **Turn raw data into decisions: clean it, model it, visualise it and tell its story.**

| | |
|---|---|
| **For** | Beginners and professionals who work with spreadsheets |
| **Prerequisites** | Comfort with basic arithmetic and percentages |
| **Estimated effort** | ~100 hours across 11 modules plus a capstone |
| **Tools** | Microsoft Excel, Power Query, Power Pivot, Power BI, DAX |
| **Primary alignment** | [Microsoft PL-300: Power BI Data Analyst](https://learn.microsoft.com/credentials/certifications/resources/study-guides/pl-300) skills measured |
| **Also aligned to** | SFIA 9: BINT@2–3, VISL@2–3, DATM@2 · data protection principles (NDPA 2023, GDPR) |
| **Credential** | PractiCode Learn Certificate: Data Analysis (Open Badges 3.0), plus an optional PL-300 exam-prep pathway |

## By the end, you can

1. Frame a business question and choose the data that answers it.
2. Clean and reshape messy data with Power Query.
3. Build a star-schema data model with correct relationships.
4. Write DAX measures, including time intelligence.
5. Design clear, honest, accessible dashboards in Power BI.
6. Share reports securely and present the insights to decision-makers.

## Modules

| # | Module | Key outcomes | Project |
|---|---|---|---|
| 1 | **Thinking like an analyst** · *Free* | Turn vague requests into answerable questions; identify data types; describe the analysis process | Rewrite five vague business requests as answerable questions |
| 2 | **Excel foundations** | Use tables, formulas, absolute and relative references, and XLOOKUP | A sales tracker |
| 3 | **Cleaning data with Power Query** | Profile data quality; remove errors; split, merge, unpivot and combine sources | Clean a messy real-world dataset |
| 4 | **Summarising with PivotTables and Power Pivot** | Aggregate, slice and summarise; build a data model in Excel | A regional summary report |
| 5 | **Statistics you'll actually use** | Describe distributions; average vs median; variance; correlation vs causation; sampling bias | A short "what does this data really say?" memo |
| 6 | **Data modelling** | Design star schemas; set relationships and cardinality; build a date table | Model a retail dataset |
| 7 | **DAX measures and time intelligence** | Write measures vs calculated columns; explain filter context; use CALCULATE and time intelligence; use visual calculations | Year-on-year KPI measures |
| 8 | **Visual design for dashboards** | Choose the right chart; use colour accessibly; avoid misleading visuals | Redesign a bad dashboard |
| 9 | **Building reports in Power BI** | Build interactive reports; use drill-through, bookmarks and AI visuals; use Copilot with care | A multi-page interactive report |
| 10 | **Sharing, security and governance** | Use workspaces and roles; apply row-level security; refresh data; meet data-protection duties | Secure a report for two regional managers |
| 11 | **Communicating insights** | Structure a data story; present with confidence; write an executive summary | A recorded or live 5-minute insight presentation |
| ★ | **Capstone** | End-to-end analysis of a real public dataset (for example, NBS Nigeria or World Bank Open Data) | A published report plus an executive summary |

## Assessment

In-lesson tasks with instant checks, module mastery checks (80% pass mark), rubric-marked projects, and a capstone. The exam-prep pathway adds timed practice exams that mirror the PL-300 skill weightings.

## Device notes

Concept lessons, formulas, statistics and DAX reasoning work on a phone, using in-browser exercises. **Power BI Desktop runs on Windows only**, so Modules 6–10 need a Windows PC or the Power BI web service. Module 6 explains the options, including free ones. We say this up front on the track page.

## Ethics and privacy

Every module that touches personal data includes the relevant principles: data minimisation, anonymisation, purpose limitation and lawful basis under Nigeria's Data Protection Act 2023 and the GDPR.
