# Open source

What PractiCode Learn publishes openly, under which licence, and how others have used it.

## What is open

| What | Where | Licence |
|---|---|---|
| The application: lesson player, labs, code runner, sign-in, progress, impact measurement | This repository | [GNU AGPL-3.0](../../LICENSE) |
| The content tools: lesson build, code checks, review preview, publishing | [`tools/content-build/`](../../tools/content-build/) | GNU AGPL-3.0 |
| The lesson format specification | [`docs/curriculum/lesson-format.md`](../curriculum/lesson-format.md) | CC BY-SA 4.0 |
| Syllabi, learning outcomes and standards mappings | [`docs/curriculum/`](../curriculum/), [`src/content/tracks/`](../../src/content/tracks/) | CC BY-SA 4.0 |
| Sample lessons | [`content/samples/`](../../content/samples/) | CC BY-SA 4.0 |
| Documentation | [`docs/`](../README.md) | CC BY-SA 4.0 |

The full lessons are not open: they fund the work. The reasoning is in [ADR 0004](../architecture/adr/0004-open-syllabus-proprietary-lessons.md), and the details are in [LICENSING.md](../../LICENSING.md).
